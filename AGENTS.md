# Project layout

Keep `spec.md`, `prompts.md`, and `index.html` at the project root. `index.html` must stay at the root for GitHub Pages.

- `00_planning/`: notes, plans, and sketches.
- `01_data/`: data files.
- `02_validation/`: hand calculations and test cases.
- `03_output/`: screenshots and exported results.

Save every new file in the folder that matches its purpose; keep the single-file web app entry point at the root.
